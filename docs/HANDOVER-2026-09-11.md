## 1. What this project is

HurlingWiki is a public, kid-friendly Galway hurling knowledge site built as an MIT **D4M-style sparse associative array**: entities and facts as `row / col / val` triples in `data/seed.json`, rendered by a Next.js App Router app on Vercel.

**Product goal (locked):** continuous long-horizon ingest of ~100 years of Galway hurling into cited **Match / Club / Player / appearance** triples — **not** full copyrighted article dumps.

**Club-first rule:** Fohenagh / Ahascragh-Fohenagh first, then other Galway clubs and county seasons.

## 2. Hard rules (do not break)

1. **Never invent scores, caps, or tallies.** If a public source does not print it, omit it or leave unverified.
2. **Cited triples only** for Match/Club/Player/appearance facts; cuttings = public thumb + short excerpt + cite chip; private OCR stays private.
3. **Appearances** are `Player × Competition → Year` + cite; stay **unverified** until Tribes Archivist CLEAR (or Garry explicitly says “verify X” in chat).
4. **Search rank:** verified → Fohenagh → provisional; HOLD = name+years+cite, **no club chip** when disputed.
5. **Never** show source as “Garry Lohan Neighbours” / personal attribution. Present AF/Fohenagh neighbour-sourced players as system-scouted club hurlers; no fake newspaper cites for those.
6. **Historic vs amalgam clubs:** pre-amalgamation Fohenagh / Ahascragh = historic club ids; amalgam **Ahascragh-Fohenagh** from ~2002 (`club:ahascragh-fohenagh`). 1959–1960 Fohenagh SHC titles stay historic predecessor titles, not amalgam wins.
7. **All-Ireland shelf:** only real All-Ireland wins — never badge county Junior/Minor as All-Ireland.
8. Git commits as **D4M** via env-only author (`D4M` / `d4m@hurlingwiki.local`) — **no `git config`**.
